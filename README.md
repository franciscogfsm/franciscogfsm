## Selected projects

### [TrackBack](https://github.com/franciscogfsm/TrackBack) — Athlete performance & feedback

A platform for athletes and coaches to track progress, organise training feedback, and make better-informed performance decisions. Features include coach dashboards, performance history, direct communication, and AI-assisted insights.

**Stack:** TypeScript · React · Supabase · Tailwind CSS · Vercel

[Source code](https://github.com/franciscogfsm/TrackBack) · [Website](https://www.thetrackback.com/)

### ShelfOS — Applied computer vision · JunctionX Lisbon 2026

An AI-powered retail shelf analysis prototype built during JunctionX Lisbon, using computer vision and Vision Transformer-based techniques to analyse products and shelf layouts.

**Result:** 🥉 3rd place, Sensei Challenge.

### RiftGen — AI-assisted creation tools · Experimental

Exploring agent-driven tooling for **Unreal Editor for Fortnite (UEFN)**: turning natural-language instructions into playable map structures, mechanics, and Verse code.
