## 💻 Featured Engineering Projects

My work spans **desktop applications, AI security, computer vision, and intelligent systems**.

### 🖥️ [Mirlow](https://github.com/franciscogfsm/Mirlow) — Open-Source Screen Mirroring

**Rust · Tauri 2 · React · TypeScript · Systems Programming**

A privacy-focused Windows desktop application designed to mirror iOS and Android devices without requiring accounts, cloud streaming, or additional mobile applications.

**Engineering Highlights**
- Desktop architecture combining **Rust, Tauri 2, and React**.
- AirPlay and Miracast protocol integration.
- Native video rendering pipelines involving **Direct3D 11 and GStreamer**.
- Device discovery, process supervision, and installer packaging.
- Modular monorepo architecture with a reusable design system.

[View Source Code](https://github.com/franciscogfsm/Mirlow) · [Project Website](https://mirlow.vercel.app/)

### 🛡️ [OVRIDE](https://github.com/franciscogfsm/ovride) — AI Agent Security

**Cybersecurity · Agentic AI · TypeScript · Next.js · LLMs**

An interactive AI security project exploring one of the biggest challenges in agentic systems: **prompt injection and unauthorised tool execution**.

OVRIDE demonstrates how malicious instructions hidden inside external content can manipulate AI agents — and how deterministic security policies can stop dangerous operations before execution.

**Engineering Highlights**
- Simulated adversarial attacks against AI agents.
- Side-by-side comparison of protected and unprotected environments.
- Deterministic tool execution policies and destination validation.
- Detailed attack traces, security verdicts, and execution timelines.
- Integration with LLM APIs for live experiments.

[View Source Code](https://github.com/franciscogfsm/ovride)

### 👁️ [ShelfOS](https://github.com/franciscogfsm/ShelfOS) — AI-Powered Retail Intelligence

**Python · Computer Vision · DINOv3 · Vision Transformers · Machine Learning**

An intelligent retail shelf analysis system developed for the **Sensei Challenge at JunctionX Lisbon 2026**.

The platform uses computer vision to analyse store shelves, compare product placement against planograms, estimate stock availability, and identify restocking opportunities.

**Engineering Highlights**
- Visual feature extraction using **DINOv3 embeddings**.
- Patch-level computer vision analysis.
- Reference-image comparison and product placement detection.
- Structured planogram analysis and stock estimation.
- Interactive visual dashboard and automated evaluation tools.

[View Source Code](https://github.com/franciscogfsm/ShelfOS) · [Live Demo](https://shelfos-demo.vercel.app/)
